Secure Render Pipeline: fetch → parse → render

This feature pulls an "article" response, turns the bytes into a value, and puts that value on the screen. Each arrow is a trust boundary. The handler in app.js owns the parse and render stages; verify.js feeds it one well-formed body and a set of malformed and hostile ones, then reports whether the pipeline fails closed. Open the browser console for the full per-fixture log.
