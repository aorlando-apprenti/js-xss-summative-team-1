Prototype Pollution via Insecure Object Handling

This page applies a benign settings update and two crafted attack payloads through the settings merge in app.js. The harness in verify.js checks whether either attack wrote onto Object.prototype — the global pollution that lets an unrelated empty object inherit an injected isAdmin. The harness scrubs the prototype after each test, so the page stays usable either way. Open the console for the per-payload log.
